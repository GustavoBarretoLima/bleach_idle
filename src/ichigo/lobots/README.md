Four 32×32 direction columns: up, right, down, left. Three rows: first step, resting stance, second step. Walk/run use rows 1,0,1,2 at different speeds. The full image is drawn at a uniform 1.25 scale with a fixed foot anchor and nearest-neighbor sampling. No mirroring or independent sword deformation.

The source does not include dedicated combat frames. Attack uses a short full-sprite lunge and slash indicator; defense uses the resting stance with a directional guard/impact indicator. Existing attack timings, defense, parry, hitboxes, and controls are unchanged. Reduced motion keeps a static stance. Original local art remains in the repository for future use.
